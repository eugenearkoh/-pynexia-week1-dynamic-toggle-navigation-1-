# Dynamic Toggle Navigation

**Pynexia Technology Internship — Week 1, Assignment 1**

## Project Overview

This project implements a responsive navigation menu using HTML, CSS, and JavaScript. It demonstrates frontend fundamentals, interactive user interfaces, and mobile-friendly design.

## Features

- Responsive navigation for mobile and desktop screens.
- Hamburger menu with animated open and close states.
- Smooth CSS transitions and visual hover effects.
- Active navigation link styling.
- JavaScript event listeners and DOM manipulation.
- Menu closes when a navigation link is selected.
- Menu closes when the user clicks outside it.
- Escape key support for closing the menu.
- Semantic HTML and accessibility attributes.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
